# FitSync 云同步接口文档

根据 `server/src/main/java/com/fitsync/cloud/ApiController.java`、请求 record、对应 Service、`ApiErrors` 和鉴权过滤器生成。覆盖当前 Controller 的 30 个接口，核对日期：2026-11-09。

基础路径为 `/api/v1`。成功响应直接返回 JSON 对象或数组；没有统一的 `code/data` 包装。除文件上传外，带请求体的接口使用 `Content-Type: application/json`。成功状态均为 HTTP `200`。

下文标注「私有」的接口必须携带 `Authorization: Bearer <token>`。用户身份由会话确定，任何请求都不接受客户端指定 `userId`。活动、账号、规则、任务及文件均验证所有权；不存在或属于其他用户的记录通常统一返回 HTTP `404`。

## 4. 建立网页登录挑战

| 属性 | 值 |
| --- | --- |
| 请求 | `POST /api/v1/auth/web-challenges` |
| 认证 | 公开 |
| 参数 | 无 |

成功响应：

| 字段 | Java 类型 | 说明 |
| --- | --- | --- |
| `id` | `String` | 随机挑战 ID |
| `code` | `String` | 10 位随机大写登录码，使用不易混淆的字母与数字 |
| `pollToken` | `String` | 仅供发起浏览器持有的随机轮询秘密 |
| `expiresAtEpochMs` | `Long` | 五分钟后的到期时间，Unix 毫秒 |

浏览器显示 `code`，已登录小程序通过第 6 个接口明确确认该码。`pollToken` 不能显示在可分享链接中，也不能作为 Query 参数发送。服务端只保存登录码与轮询秘密的哈希。生产页面依据 `webLoginEnabled` 控制入口；挑战创建本身不检查微信配置。

## 5. 轮询网页登录结果

| 属性 | 值 |
| --- | --- |
| 请求 | `GET /api/v1/auth/web-challenges/{id}` |
| 认证 | 无需 Bearer，但必须持有原浏览器的轮询秘密 |

| 位置 | 参数 | Java 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| Path | `id` | `String` | 是 | 第 4 个接口返回的挑战 ID |
| Header | `X-Login-Poll-Token` | `String` | 业务必填 | 第 4 个接口返回的 `pollToken`，最长 128 字符 |

待确认、已过期、已消费时分别返回：

```json
{"status":"PENDING"}
```

```json
{"status":"EXPIRED"}
```

```json
{"status":"CONSUMED"}
```

确认成功后的首次有效轮询返回 `LoginResponse` 的 `token`、`user`，并额外包含 `status: "CONFIRMED"`。同一个挑战只允许消费一次；成功后应停止轮询并保存会话。错误的挑战 ID、遗漏或错误的轮询秘密返回 `404`。轮询建议每 3 秒一次。

## 6. 在小程序确认网页登录

| 属性 | 值 |
| --- | --- |
| 请求 | `POST /api/v1/auth/web-challenges/confirm` |
| 认证 | 私有 |

| JSON 字段 | Java 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | `String` | 是 | 网页显示的 10 位登录码；服务端去首尾空白并转大写 |
| `confirm` | `boolean` | 是 | 必须为 `true`；缺省为 `false` 并被拒绝 |

页面需明确说明「确认将我的 FitSync 账号登录到该网页」，由用户主动提交。成功返回：

```json
{"confirmed":true}
```

此响应不包含新会话；会话只允许原浏览器通过轮询秘密领取。过期、已确认、已消费的码不能再次确认，也不能被另一用户覆盖，返回 HTTP `400`。

| 认证 | 私有 |

| JSON 字段 | Java 类型 | 必填 | 说明 |
| --- | --- | --- | --- |

## 11. 导入 FIT 文件

| 属性 | 值 |

| Part 参数 | 类型 | 必填 | 说明 |

成功后规划符合已启用规则的投递。格式、CRC、文件大小或活动校验失败返回 `400`；不会创建伪活动。

## 14. 复核疑似重复活动（保持分离或合并到候选）

| 属性 | 值 |
| --- | --- |
| 请求 | `POST /api/v1/activities/{id}/review` |
| 认证 | 私有 |
| Path 参数 | `id: String`，必填，待复核活动 ID |

| JSON 字段 | Java 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `decision` | `String` | 是 | 支持 `KEEP_SEPARATE`（保持分离）或 `MERGE_INTO_CANDIDATE`（合并到候选活动） |

`KEEP_SEPARATE` 解除 `needsReview` 并清除候选关系后重新按已启用规则规划投递；已处于非复核状态时保持幂等。`MERGE_INTO_CANDIDATE` 将当前活动的 FIT 副本、平台映射及非冲突任务迁移合并到候选活动后删除重复记录，并返回合并后的 `activityId`（目标候选 ID）和 `movedVariants`。其他 `decision` 返回 `400`。

## 16. 连接或重新授权平台账号

| 属性 | 值 |
| --- | --- |
| 请求 | `POST /api/v1/accounts` |
| 认证 | 私有 |

| JSON 字段 | Java 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `platform` | `String` | 是 | `COROS` 或 `IGPSPORT`；此接口会转为大写 |
| `username` | `String` | 是 | 非空，最长 160 字符 |
| `password` | `String` | 是 | 非空，最长 512 字符 |
| `storeCredentials` | `boolean` | 否 | 默认 `false`；只有明确为 `true` 才保留供令牌失效后自动重登的账号密码 |

立即调用真实平台登录协议；成功返回 `AccountSummary`。每个用户每个平台最多一个账号。同一平台身份重新授权复用账号 ID；识别为不同远端身份时拒绝，要求先解绑旧账号。

令牌与经用户同意托管的密码使用绑定用户、账号的 AES-GCM 加密保存，不回传。未托管密码时令牌失效会暂停相关任务并要求重新连接。账号正在执行同步、登录失败、不支持的平台或换绑身份均返回 `400`。

| `session.token` | `String` | 按平台 | 迈金 localStorage 的 token，迈金必填 |
| `session.refreshToken` | `String` | 否 | 迈金 refresh_token，用于后台静默续期 |
| `session.csrf` | `String` | 否 | Garmin `Connect-Csrf-Token` |
| `session.ssoCookie` | `String` | 否 | Garmin `sso.garmin.cn` Cookie，用于静默续期 |
| `session.externalUserId` | `String` | 否 | 平台用户 ID，用于换绑校验 |
| `session.userAgent` | `String` | 否 | 登录时使用的浏览器 UA |

服务端先做只读探活（迈金活动列表、行者活动列表、Garmin 活动列表、Strava 上传页），成功后创建或复用 `(user,platform)` 账号，返回 `AccountSummary`。会话字段与其他平台凭据一样使用绑定用户与账号的 AES-GCM 加密保存，不写入日志、不回传。字段总长超过限制、含换行、缺少平台必需字段或探活失败时返回 HTTP `400`。网页会话方案不能绕过验证码、二次认证或平台风控；会话失效后需重新登录并提供新值。

桌面 Chrome／Edge 用户可通过 [FitSync 会话助手扩展](../clients/browser-extension/README.md) 自动完成上述填写与提交：网页请求扩展弹出平台官方登录窗口，用户人工登录后，扩展读取 HttpOnly Cookie 并调用本接口。该流程需要把扩展的 `chrome-extension://<扩展ID>` 来源显式加入服务端 CORS 白名单；服务端不因此放宽其他来源。

## 21. 提交手动同步或拉取

| 属性 | 值 |
| --- | --- |
| 请求 | `POST /api/v1/sync` |
| 认证 | 私有 |

| `sourcePlatform` | `String` | 按模式 | 未选择活动时使用 `COROS`、`IGPSPORT` 或 `LOCAL`；此接口不自动转大写 |

| 模式 | 参数组合 | 行为 |
| --- | --- | --- |
| 仅拉取来源 | 已连接云平台来源，`destinationAccountIds=[]`，不传非空 `activityIds` | 仅创建来源 `PULL` 任务 |

成功返回 `{"jobIds":["任务UUID"]}`，字段类型为 `List<String>`。这是已入队任务 ID，不表示平台已接收或同步已完成。重复规划的投递可能返回已有任务 ID；已有目标副本或待复核活动不会生成新的投递任务。通过第 22 个接口查看最终结果。

本地没有合格活动、选择超过 100 条、本地或指定活动模式没有目标、回填天数非法返回 `400`；账号、活动不存在或属于其他用户返回 `404`。

## 通用说明

### 登录响应与用户对象

`LoginResponse`：

| 字段 | Java 类型 | 说明 |
| --- | --- | --- |
| `token` | `String` | 随机业务 Bearer Token，后续私有请求通过认证头携带 |
| `user` | `User` | 当前业务用户 |
| `user.id` | `String` | 用户 UUID |
| `user.displayName` | `String` | 展示名 |

Token 默认 30 天有效，数据库只保存 SHA-256 哈希。网页登录的成功消费响应额外包含 `status: "CONFIRMED"`。FitSync 业务账号支持用户名密码注册登录（第 24、25 个接口），密码只保存 PBKDF2-HMAC-SHA256 加盐散列；微信小程序一键登录与网页确认码登录继续保留，且可通过绑定微信与补设密码把不同登录方式统一到同一业务用户。不提供公开 Token 刷新或忘记密码自助找回接口（后者需短信或邮箱服务）。

### 枚举

| 枚举 | 值 | 说明 |
| --- | --- | --- |
| 平台来源 | `LOCAL` | 文件导入来源，不是平台账号 |
| 云端连接平台 | `COROS`、`IGPSPORT` | 账号密码协议连接器 |
| 网页会话平台 | `ONELAP`、`XINGZHE`、`GARMIN`、`STRAVA` | 用户显式导入网页登录会话，`authMode=WEB_SESSION` |
| 账号状态 | `CONNECTED` | 登录成功，可尝试运行云端任务 |
| 账号状态 | `AUTH_EXPIRED` | 登录失效，需重新连接 |
| 任务种类 | `PULL` | 拉取活动、下载原始 FIT 并导入 |
| 任务种类 | `DELIVERY` | 投递已保存的 FIT 并确认真实远端活动 ID |
| 任务状态 | `PENDING` | 等待执行或下一页继续 |
| 任务状态 | `RUNNING` | 已领取执行租约 |
| 任务状态 | `CONFIRMING` | 平台已受理或上传结果需确认，只查询确认，不重新上传 |
| 任务状态 | `RETRY` | 等待退避重试 |
| 任务状态 | `SUCCEEDED` | 拉取完成或投递已确认 |
| 任务状态 | `WAITING_USER` | 需重新登录、人工核对或处理其他用户操作 |
| 任务状态 | `FAILED` | 永久失败；可按实际错误处理后请求重试 |
| 任务状态 | `CANCELLED` | 自动规则已关闭或删除，尚未开始上传的任务被取消 |
| 运动类型 | `CYCLING`、`INDOOR_CYCLING`、`MTB`、`GRAVEL`、`RUNNING`、`OTHER`、`UNKNOWN` | FIT 解析器输出 |
| 复核决策 | `KEEP_SEPARATE`、`MERGE_INTO_CANDIDATE` | 保持为独立活动，或合并到候选活动并迁移副本 |

### 错误响应

应用错误以对应 HTTP 状态返回 JSON：

```json
{"code":"UNAUTHORIZED","message":"请先登录"}
```

| HTTP 状态 | `code` | 说明 |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | 请求、业务参数、FIT 校验或当前操作状态不允许 |
| `401` | `UNAUTHORIZED` | 缺少 Bearer、会话无效或过期 |
| `404` | `NOT_FOUND` | 记录不存在、所有权不符、开发登录未启用，或网页登录轮询秘密不匹配 |
| `429` | `RATE_LIMITED` | 认证接口限频，响应头包含 `Retry-After: 60` |
| `500` | `INTERNAL_ERROR` | 未处理的服务错误，返回通用中文提示 |

默认每个服务实例按客户端 IP 对认证接口共享每分钟 30 次限制；挑战 `GET` 轮询单独默认每分钟 90 次。限频涵盖 `/api/v1/auth/register`、`/api/v1/auth/login` 等所有 `/api/v1/auth/` 路径。限频参数可配置，未实现跨实例共享计数；公开部署仍需网关层防暴力破解。CORS 会在进入 Controller 前按域名白名单处理，允许的 HTTP 方法为 `GET`、`POST`、`PUT`、`DELETE`、`OPTIONS`。

### 类型、缓存与时间

表中类型来自 Java record、Service 与 JDBC 聚合响应。JSON 不包含 Java 类型标签。可空字段在无值时可能不返回，客户端应同时处理缺省与空值。时间统一为 Unix epoch 毫秒，距离为米、时长为秒；没有日期字符串转换约定。API 与私有文件响应设置 `Cache-Control: no-store`。

### 同步与上线验证边界

数据库队列在前端关闭后继续运行，保存游标、退避与远端确认状态。投递固定入队文件副本，并对同一活动和目标账号加唯一约束；更换主副本不会在未知上传期间发起第二次 POST。疑似重复活动必须先明确复核。定时任务默认启用，可通过服务配置停用。

本地集成测试使用 H2 与模拟连接器，不能视为真实平台、生产 PostgreSQL 或微信线上联调通过。用户名密码注册登录、绑定状态与密码散列有 H2 集成测试；微信 `code2session` 绑定仍需真实微信环境验证。生产 PostgreSQL、真实 COROS/iGPSPORT 账号、微信登录与个人主体后台权限均需部署环境验证。广告配置只透出真实广告位占位；流量主资格、广告填充和收益结算尚未验证，服务端激励验证没有配置时不发放额度、不记录虚构收益。
